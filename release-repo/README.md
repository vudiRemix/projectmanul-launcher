# Репозиторий сборки

Эти файлы лежат в **публичном** репозитории на GitHub. Лаунчер читает их напрямую.

| Файл | Что в нём | Кто меняет |
| --- | --- | --- |
| `config.json` | адрес сервера, адрес проверки ника, режим техработ | админ, прямо в веб-интерфейсе GitHub |
| `news.json` | новости в лаунчере (RU/EN) | админ, прямо в веб-интерфейсе GitHub |
| Releases | моды, конфиги и подписанный `manifest.json` | только скрипт `npm run release` |

Изменения в `config.json` и `news.json` доходят до игроков за ~5 минут (кеш GitHub).

## Новость

```json
{
  "date": "2026-11-24",
  "tag": { "ru": "Обновление", "en": "Update" },
  "title": { "ru": "Заголовок", "en": "Title" },
  "text": { "ru": "Текст", "en": "Text" },
  "image": "https://… (необязательно)",
  "link": "https://… (необязательно)"
}
```

Новые новости добавляйте в начало списка `items`. Поля можно писать и простой строкой — тогда текст одинаковый на обоих языках.

## Сервер

- `server.host` / `server.port` — куда подключается игра и откуда лаунчер берёт онлайн.
- `nickCheckUrl` — адрес плагина NickCheck, `{nick}` подставляется автоматически.
- `maintenance.enabled: true` — в лаунчере вместо «В сети» будет «Техработы» и ваш текст.
